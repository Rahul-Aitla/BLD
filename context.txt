Goal

Understand the complete system before coding.
I am building a remote browser system.

Requirements:
- Chromium must run in headless mode inside Docker.
- Frontend should receive a live browser stream.
- Frontend should send mouse, keyboard, and scroll events.
- Backend should control Chromium using Playwright.
- Streaming should use WebRTC.
- Signaling should use Socket.IO.


Only build one phase at a time.
Phase 1
Create Docker Browser Container
Goal

Run headless Chromium.

IDE Prompt
Create a Docker container that runs:
- Node.js
- Playwright
- Chromium

Chromium must launch using:

--headless=new
--remote-debugging-port=9222

Expose port 9222.

Create a health endpoint that confirms Chromium is running.

Chrome supports remote debugging in headless mode.

Deliverable:

docker compose up

Browser starts successfully.

Implement:

Return working TypeScript code.

Backend controls browser.
Phase 3
CDP Screencast

This is the most important phase.

Chrome DevTools Protocol exposes:

Page.startScreencast

which continuously sends rendered frames.

IDE Prompt
Using Chrome DevTools Protocol:

Connect to headless Chromium.

Enable:
Page.enable

Start:
Page.startScreencast

Receive:
Page.screencastFrame

Acknowledge frames using:
Page.screencastFrameAck

Print frame sizes and timestamps.

Use TypeScript.

Deliverable:

Frames arriving continuously.

One thing I would change

If this were my submission, I would build Phase 1 → Phase 9 completely without Docker first.

Once:

WebRTC works
CDP screencast works
Playwright control works

then I would move Chromium into Docker.

That reduces debugging difficulty by almost 70%.

Most developers fail because they debug:

Docker
+
Chromium
+
CDP
+
WebRTC
+
React

all at once.

Build the browser system locally first.

Containerize last.

Biggest risk: Phase 4 — converting CDP JPEG frames into a RTCVideoSource via node-webrtc. This is the part most people get stuck on. If you hit a wall there, JPEG-over-WebSocket (what I built) is a valid fallback that still demonstrates the core concept.
